### 👨‍💻 Sobre
Atualmente cursando o 1º período de Análise e Desenvolvimento de Sistemas na UNICID. Sou apaixonado por resolver problemas complexos através da tecnologia, com foco estratégico em Cybersegurança e Defesa Cibernética. Possuo sólida base teórica em infraestrutura de redes e segurança de dados, buscando constantemente aplicar boas práticas de proteção em ambientes de desenvolvimento.

Habilidades Técnicas: Desenvolvimento em Python, Java e C# (em evolução); Gestão de Bancos de Dados (SQL); Infraestrutura de Redes; Desenvolvimento Web (HTML/CSS) e Engenharia de Prompt para IA.

Habilidades Socioemocionais: Comunicação assertiva, trabalho em equipe, proatividade, organização e pensamento crítico
