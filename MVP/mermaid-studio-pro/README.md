# 🧠 Projeto de Inteligência Artificial

## 📝 Descrição do Projeto

Este projeto foi desenvolvido com o objetivo de explorar aplicações práticas da Inteligência Artificial, utilizando recursos de IA generativa para apoiar processos de análise, desenvolvimento e automação de tarefas.

A proposta central do projeto é demonstrar como a Inteligência Artificial pode ser utilizada como ferramenta estratégica no desenvolvimento de soluções modernas, incentivando criatividade, produtividade e pensamento crítico durante a construção de projetos tecnológicos.

Desenvolvido como parte dos estudos em **Inteligência Artificial**, o projeto apresenta conceitos relacionados à utilização consciente da IA, engenharia de prompts e integração de ferramentas inteligentes em ambientes acadêmicos e profissionais.

## 📊 Resultados e Aprendizados

O projeto proporcionou experiências importantes no desenvolvimento de aplicações utilizando Inteligência Artificial.

* **Engenharia de Prompt:** Aprimoramento da criação de prompts mais eficientes e estratégicos.
* **Produtividade Inteligente:** Utilização da IA como ferramenta de apoio no desenvolvimento de tarefas.
* **Criatividade e Inovação:** Exploração de novas possibilidades utilizando IA generativa.
* **Pensamento Analítico:** Desenvolvimento da capacidade de avaliar resultados produzidos pela IA de forma crítica.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/8ae2c11d-47e3-4ce5-b503-d6b60460a7c0

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
