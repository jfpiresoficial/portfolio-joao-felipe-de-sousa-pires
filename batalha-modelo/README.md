# 🤖 Comparativo de Inteligências Artificiais para Criação de Conteúdo

## 📝 Descrição do Projeto

Este projeto consiste em uma análise comparativa entre diferentes modelos de Inteligência Artificial aplicados na geração de conteúdo e desenvolvimento em HTML. O objetivo principal foi avaliar o desempenho das IAs em critérios como precisão do resultado, criatividade, qualidade do código gerado, quantidade de tokens utilizados e ocorrência de erros de sintaxe.

Desenvolvido como atividade acadêmica, o projeto realizou testes práticos com os modelos **GPT, Gemini, DeepSeek, Qwen, Grok, Maritaca e Claude**, utilizando prompts estruturados em XML para analisar a capacidade de interpretação e geração de conteúdo de cada ferramenta.

A análise permitiu identificar diferenças relevantes entre os modelos, destacando pontos fortes e limitações em tarefas de prototipagem rápida, criatividade e desenvolvimento de códigos mais complexos.

## 📊 Resultados e Aprendizados

O projeto trouxe uma visão prática sobre o comportamento de diferentes modelos de IA em cenários reais de criação de conteúdo.

### 🔍 Principais Resultados

* **Gemini** apresentou excelente compreensão da estrutura do prompt em XML.
* **Claude** foi o modelo mais estável, sem apresentar bugs detectados.
* **Qwen** e **Maritaca** demonstraram bom desempenho em criatividade e geração de informações.
* Alguns modelos apresentaram falhas relacionadas à ausência de imagens e conflitos visuais no HTML gerado.

### 📚 Aprendizados Obtidos

* Compreensão das diferenças entre modelos de IA generativa.
* Avaliação prática da relação entre quantidade de tokens e qualidade da resposta.
* Identificação das melhores ferramentas para:
  * **Prototipagem rápida:** Gemini
  * **Códigos mais complexos:** Maritaca e Qwen
* Aprendizado sobre estruturação de prompts em XML para melhorar resultados.
