# 🧠 Classificação Visual com IA

## 📝 Descrição do Projeto

Este projeto consiste em uma aplicação de **Classificação Visual utilizando Inteligência Artificial**, desenvolvida com a plataforma Google Teachable Machine como parte da disciplina de **Engenharia de Prompt e Aplicações em IA**.

O sistema tem como objetivo realizar análises comparativas entre perfis de pessoas, utilizando como tema principal a comparação entre características associadas às culturas **italiana** e **francesa**. A proposta busca identificar padrões visuais presentes em imagens faciais e classificá-los com base no treinamento realizado no modelo de IA.

A aplicação explora conceitos de visão computacional e aprendizado de máquina de forma prática, permitindo compreender como algoritmos de classificação podem apresentar resultados distintos conforme a qualidade e quantidade dos dados utilizados no treinamento.

## 📊 Resultados e Aprendizados

Durante o desenvolvimento do projeto, foi possível observar diversos aspectos importantes relacionados ao treinamento de modelos de IA.

### ✅ Principais Aprendizados

* Compreensão prática sobre treinamento de modelos visuais.
* Identificação da influência da qualidade dos dados no resultado da IA.
* Aplicação de conceitos de reconhecimento facial e padrões visuais.
* Entendimento sobre viés algorítmico em bases pequenas de treinamento.

---

## ⚠️ Limitações do Projeto

O modelo foi treinado utilizando aproximadamente **20 imagens**, o que reduz a capacidade de análise avançada da IA e pode gerar classificações imprecisas.

### Exemplo observado:
Mesmo sendo brasileiro, algumas características faciais foram interpretadas pelo modelo como descendência italiana.

Isso demonstra como modelos com poucas imagens podem desenvolver padrões limitados e vieses durante o treinamento.

---

## 🧩 Mecanismo de Viés

Foi observado que determinadas características faciais, como o formato do nariz, influenciaram diretamente o resultado das classificações.

Esse comportamento evidencia como algoritmos podem criar associações baseadas em padrões restritos presentes na base de treinamento.

---

## 🛠️ Ação Mitigadora

Para aumentar a precisão do modelo, a principal melhoria proposta é:

* Adicionar uma quantidade maior e mais diversificada de imagens no treinamento.
* Melhorar a variedade cultural e visual da base de dados.
* Reduzir vieses causados por padrões limitados.
